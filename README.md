# Practic work №2: Розробка персонажів, Карта емпатії та CJM

##  Проєкт: VIP-платформа ПВК «The CERBERUS»
Інтерактивний веб-дашборд UX-дослідження цільової аудиторії для платформи приватних військових послуг та курсів із виживання.

##  Реалізовані UX-артефакти
1. **User Personas (3 репрезентативні персони):**
   * *Маркус Венс (48 р., CSO)* — первинний B2B-замовник охорони стратегічних об'єктів.
   * *Олена Ковальчук (31 р., військовий журналіст)* — клієнт інтенсивних курсів виживання.
   * *Артур Стерлінг (39 р., інвестор)* — VIP-клієнт послуг особистої охорони.
2. **Negative / Anti-Persona (Просунутий рівень):**
   * *Денис (19 р., студент-геймер)* — профіль нецільової аудиторії та механізми її фільтрації через UI.
3. **Empathy Map (Карта емпатії):**
   * Детальний аналіз думок, емоцій, оточення, болей (Pains) та вигод (Gains) ключової персони Маркуса Венса.
4. **User Journey Map (CJM — Просунутий рівень):**
   * Покрокова карта шляху користувача від моменту виникнення загрози на об'єкті до підтвердження контракту зі штабом ПВК.

##  Технологічний стек
* **HTML5 / CSS3** — адаптивна модульна сітка (CSS Grid), темна тактична тема (`#06090E` / `#C5954B`).
* **JavaScript (ES6)** — інтерактивна навігація між артефактами в межах єдиної сторінки (SPA).

## Запуск проєкту
Відкрийте файл `index.html` у будь-якому сучасному браузері. Перемикання між артефактами реалізовано через верхню панель вкладок.
